How to read this. Frozen replays the attacks that worked, unchanged, against the defended agent. Mutation retry tries every attack again against the defenses with the same four mutations. Frozen alone overstates how safe the agent is; the adaptive attacker below, which rewrites its attacks, is the stronger test. Goal met counts only breaches where the attacker got what that attack asked for. Small n means wide confidence intervals.

Adaptive attacker

An attacker model writes an attack, reads the agent's reply, and rewrites it, up to the number of rounds shown, knowing which defenses are on (PAIR-style, Chao et al. 2023). It never sees the system prompt or the secrets. The verifier, not the attacker, decides what counts.
